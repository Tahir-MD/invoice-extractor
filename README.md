# 📊 Invoice Data Extractor

A powerful, web-based invoice analysis tool built with Streamlit. Extract insights, visualize data, and generate reports from your invoice files.

## 🌟 Features

- **📈 Interactive Dashboard** - Real-time metrics and visualizations
- **📋 Data Explorer** - Search, filter, and export your data
- **📊 Advanced Analytics** - Customer segmentation, trend analysis, correlations
- **💡 Business Insights** - Automatic insight generation
- **📥 Export Options** - Download as CSV or Excel with summaries
- **📱 Mobile Responsive** - Works on all devices

## 🚀 Quick Start

### Local Installation

```bash
# Clone the repository
git clone https://github.com/Tahir-MD/invoice-extractor.git
cd invoice-extractor

# Install dependencies
pip install -r requirements.txt

# Run the app
streamlit run app.py
